Android Room

Room 是 Google 官方推出的 SQLite 数据库封装库，属于 Jetpack 组件，核心是简化 SQLite 操作、提供编译时 SQL 校验、支持 LiveData/Flow 响应式查询，彻底告别原生 SQLite 的繁琐模板代码，是 Android 本地数据存储的首选方案。

一、核心组件（三大核心）

Room 基于注解驱动，核心由 3 个组件构成，分工明确：

  1. Entity（实体类）：对应数据库表，用注解标记表名、字段、主键、约束等，是数据的载体。

  2. DAO（数据访问对象）：定义数据库操作接口（增删改查），通过注解绑定 SQL 语句，Room 自动生成实现类。

  3. Database（数据库类）：继承 RoomDatabase，是数据库的入口，管理数据库版本、关联 Entity、提供 DAO 实例。

五、常见问题与注意事项

  1. 主线程操作异常：Room 强制要求数据库操作在子线程，可用 Executor、Coroutine、RxJava 处理。

  2. 字段必须有 Getter/Setter：Room 通过反射访问字段，缺少会编译报错。

  3. 实体类必须有无参构造：Room 实例化对象需要无参构造。

  4. 版本升级谨慎：生产环境必须用 Migration，避免数据丢失。

  5. KSP 替代 kapt：新版 Room 推荐 KSP，编译速度更快，兼容性更好。
