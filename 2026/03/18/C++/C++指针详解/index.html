C++中指针的核心概念讲解

一、指针的核心概念（基础）

指针的本质是存储内存地址的变量，就像一个 “门牌号”，通过它可以找到对应内存位置的数据。

1. 基本语法

2. 关键术语

  • &：取地址运算符，获取变量的内存地址。

  • *：解引用运算符，通过地址访问对应内存的数据。

  • 指针的类型：int*、char*、float* 等，决定了解引用时访问的内存大小（如int*访问 4 字节）。

二、二阶指针（二级指针）

二阶指针是存储指针变量地址的指针，可以理解为 “门牌号的门牌号”，常用于多层数据传递（如函数中修改指针本身）。

六、指针与结构体

指针可以指向结构体，用于高效访问 / 修改结构体成员，尤其适合传递大结构体（避免拷贝）。

七. 总结

  1. 核心本质：指针是存储内存地址的变量，&取地址、*解引用是核心操作；

  2. 关键扩展：

  • 数组本身就是指针 int a[10] a等价与&a[0] 类型为int*；

  • 二维数组 int a[3][4] a等价与&a[0] 类型为int(*)[4]

  • 二维数组 int a[4][5] a[3]等价与&a[3][0] 类型为int*(a[3]本身为int[5],退化为指针)

  • 二阶指针：指向指针的指针，用于修改指针本身（如动态分配内存）；

  • 指针数组：数组元素是指针，常用于管理多个字符串 / 结构体；

  1. 关联场景：

  • 数组名是常量指针，一维数组可用*(p+i)替代arr[i]，二维数组需注意指针类型（int (*)[n]）；

  • 字符串本质是字符数组，指针可高效遍历 / 操作，字符串常量不可修改；

  • 结构体指针用->访问成员，适合传递大结构体（减少拷贝开销）。
