🎯 关键注意事项（新手必看）

  1. 权限控制：

  • android:exported="false"：仅当前 App 可访问（推荐内部使用）；

  • android:exported="true"：允许其他 App 访问，但需配合 readPermission/writePermission 避免数据泄露。

  1. Cursor 必须关闭：查询数据后，cursor.close() 否则会导致内存泄漏。

  2. _id 字段：数据库表必须包含 _id 主键（ContentProvider 规范，否则 Cursor 无法正常使用）。

  3. 数据变化通知：notifyChange(uri, null) 会触发监听该 URI 的 ContentObserver，可用于自动刷新 UI。
