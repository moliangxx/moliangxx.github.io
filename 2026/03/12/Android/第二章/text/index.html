Android Text运用

发表于2026-03-12|更新于2026-03-17|Android第二章
|浏览量:

text运用

注：java,android7

layout中text文本设置

1. 添加文本

把所有文本统一存放在 res/values/strings.xml 中，通过资源 ID 引用，支持多语言适配和统一修改。

步骤 1：在 strings.xml 中定义文本

格式：[文本]

步骤 2：在布局中引用资源

格式：android:text=”@string/[name]”

步骤 3： 设置属性完善xml布局

2.文本属性

  1. 设置ID android:id="@+id/[名字]"

    • text文本id前缀一般为tv

  2. android:layout_width="值"
    android:layout_height="值"

  • wrap_content：宽度自适应控件内容（比如文本多长，宽度就多长）

  • match_parent：宽度占满父布局的全部宽度（充满父容器）

  • 固定值：如100dp，固定宽度（极少用，优先自适应 / 占满）

    • 外边距： android:layout_margin="数值dp"
      1. android:layout_marginTop=”dp”顶部与其他元素的距离

    • 作用：控件和外部其他控件 / 父布局的间距（控件的外间距）

    • 衍生属性（精准控制单边）：android:layout_marginTop="20dp" 如 | layout_marginLeft | layout_marginRight | layout_marginBottom

  • android:padding="数值dp" （内边距）

    • 作用：控件内容和控件边框的间距（控件的内间距，比如 TextView 的文字和控件边缘的距离）

    • 衍生属性：paddingLeft/paddingTop/paddingRight/paddingBottom

  1. 字体大小 android:textSize="数值sp"
    • 作用：设置文字大小，单位必须用 sp 自适应
  2. 字体颜色 android:textColor="颜色值"
  • 两种用法
  • 十六进制：#RRGGBB（如#000000黑色、#FFFFFF白色、#00FF00绿色）
  • 系统自带色：@android:color/black（黑色）、@android:color/red（红色），无需手写十六进制
  1. 字体样式android:textStyle="值"
  • 取值 3 种（可组合）：normal(默认，正常) | bold(粗体) | italic(斜体)
  • 组合写法：android:textStyle="bold|italic" （粗体 + 斜体）
  1. 单换行：android:singleLine="true/false"
  • 作用：是否让文本单行显示，true = 单行，false = 自动换行（默认）

……剩下不常用懒得写了

3.约束布局

常见报错原因，没有约束布局，尤其是多个文本

必须同时具有水平布局约束和垂直布局约束

✔️ 约束的核心规则

约束布局的本质：给控件「绑上约束」，通过「相对位置」定位控件，

必须给控件加足够的约束，否则控件会消失 / 居中重叠

常用居中布局设置
  1. app:layout_constraintTop_toTopOf="parent"
  • 作用：当前控件的「顶部」 → 对齐 → 父布局的「顶部」

2.app:layout_constraintBottom_toBottomOf="parent"

  • 作用：当前控件的「底部」 → 对齐 → 父布局的「底部」

3.app:layout_constraintStart_toStartOf="parent"

  • 作用：当前控件的「左侧」 → 对齐 → 父布局的「左侧」（Start = 左，适配多语言）

4.app:layout_constraintEnd_toEndOf="parent"

  • 作用：当前控件的「右侧」 → 对齐 → 父布局的「右侧」（End = 右）
其他布局约束
  1. app:layout_constraintTop_toBottomOf="@+id/tv_first_text"
  • 作用：当前控件的「顶部」 → 对齐 → 目标控件（tv_first_text）的「底部」（垂直排列核心）
  1. app:layout_constraintStart_toStartOf="@+id/tv_first_text"
  • 作用：当前控件的「左侧」 → 对齐 → 目标控件的「左侧」（水平对齐核心）
  1. app:layout_constraintEnd_toEndOf="@+id/tv_first_text"
  • 作用：当前控件的「右侧」 → 对齐 → 目标控件的「右侧」（水平对齐核心）

Android TextView 常用属性速查表

分类 属性名 核心作用 取值 / 语法示例 关键注意事项
🔹 基础内容 android:text 设置显示文本 1. 硬编码："Hello" 资源引用：@string/hello（推荐） 禁止硬编码，优先用 strings.xml 资源
android:hint 文本为空时的提示文字 "请输入内容" 或 @string/hint_input 仅占位，文本有值时自动隐藏
android:textAllCaps 是否转为全大写 true / false（默认） 适合按钮文本，避免手动写大写
🔹 文本样式 android:textSize 设置字体大小 14sp / 20sp（必须用 sp 单位） ❌ 禁止用 dp，sp 随系统字体大小适配
android:textColor 设置字体颜色 1. 十六进制：#FF0000（红）、#80FF0000（半透明红） 2. 资源引用：@color/red 推荐用 color.xml 资源管理颜色，统一风格
android:textStyle 设置字体样式 normal（默认）/ bold（加粗）/ italic（斜体）/ `bold italic`（组合）
android:fontFamily 设置字体家族 系统字体：sans-serif（默认）、sans-serif-medium、serif ：@font/my_font Android 8.0+ 支持自定义字体，需放在 res/font 目录
android:textAlignment 文本对齐方式 start（左对齐）/ center（居中）/ end（右对齐）/ justify（两端对齐） 需配合 width="match_parent" 生效，wrap_content 下可能无效
🔹 文本排版 android:maxLines 最大显示行数 1 / 2 / 3（0 表示无限制） 配合 ellipsize 解决文本过长问题
android:ellipsize 文本过长时省略方式 end（末尾省略，常用）/ middle（中间省略）/ marquee（跑马灯） 需搭配 maxLines="1" 使用，跑马灯需设置 focusable="true"
android:lines 强制显示固定行数 2（无论文本长短，都占 2 行高度） 不推荐滥用，优先用 maxLines 更灵活
android:lineSpacingExtra 行间距额外增加量 4dp / 8dp（正数增加，负数减少） 控制多行文本的垂直间距，提升可读性
🔹 布局约束 android:layout_width 控件宽度 wrap_content（自适应）/ match_parent（占满父布局）/ 0dp（match_constraint） 优先用 0dp + 约束，性能更优
android:layout_height 控件高度 同宽度取值 避免嵌套 wrap_content，增加布局测量耗时
android:layout_margin 控件外部间距 10dp（上下左右统一间距）/ 单独设置：marginTop/marginLeft 单位必须用 dp，控制控件与其他控件的距离
android:padding 控件内部间距 8dp（文本与控件边缘的距离） 避免文本紧贴控件边框，提升美观度
app:layout_constraintTop_toBottomOf 垂直约束（上方依赖） @+id/tv_first（当前控件顶部依赖目标控件底部） ConstraintLayout 核心属性，建立控件间依赖关系
app:layout_constraintStart_toStartOf 水平约束（左侧对齐） parent（与父布局左对齐）/ @+id/tv_first（与目标控件左对齐） 确保控件位置稳定，避免布局错乱
🔹 交互相关 android:clickable 是否可点击 true / false（默认） 需设置为 true 才能响应点击事件
android:focusable 是否可获取焦点 true / false 跑马灯效果、TV 端开发必需
android:enabled 是否启用控件 true（默认，可点击 / 显示正常）/ false（灰色不可用） 控制控件启用状态，无需手动改颜色
🔹 其他常用 android:id 控件唯一标识 @+id/tv_username（必须以 @+id/ 开头） 用于 Java 代码中查找控件、布局约束依赖
android:visibility 控件可见性 visible（默认显示）/ invisible（隐藏但占位置）/ gone（隐藏不占位置） 根据业务逻辑动态控制，gone 更节省布局空间
