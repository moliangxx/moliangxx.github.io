Android Intent

一、基础概念：什么是 Intent？

1. 通俗理解

Intent 是 Android 中的「信使 / 意图」，负责在 Activity、Service、BroadcastReceiver 等组件之间传递消息，核心作用是：

  • 启动其他组件（如页面跳转、启动服务）

  • 在组件之间传递数据

可以把它想象成「快递员」：你告诉它要去的目的地（目标组件）和要带的包裹（数据），它就会帮你完成传递。

2. 核心分类

类型 特点 适用场景
显式 Intent 明确指定目标组件的类名（如 MainActivity.this, Activity2.class） APP 内部页面跳转（开发中最常用）
隐式 Intent 不指定目标组件，通过 Action 和 Category 让系统匹配能处理的组件 调用系统应用（如浏览器、电话）、APP 内隐式跳转

3. 核心组成（隐式 Intent 关键）

  • Action：要执行的动作（如 Intent.ACTION_VIEW 表示「查看内容」，自定义动作如 com.example.myapplication.ACTION_GO_TO_ACTIVITY3）

  • Category：动作的附加类别（隐式 Intent 必须包含 Intent.CATEGORY_DEFAULT）

  • Data：传递的数据（如网址、文件路径）

  • Extra：携带的额外数据（如字符串、数字、对象）

三、隐式 Intent：系统匹配跳转

1. 核心原理

隐式 Intent 不指定目标组件，而是通过 Action 和 Category 告诉系统「我要做什么」，系统会自动匹配手机中能处理该动作的组件。

  • intent-filter 必须包含 Intent.CATEGORY_DEFAULT，否则无法匹配

  • Action 名称必须和 Manifest 中配置的完全一致（大小写、拼写不能错）

3. 注意事项

  • 请求码（requestCode）必须唯一，用于区分多个跳转

  • setResult 必须在 finish() 之前调用，否则数据无法传递

  • 接收数据时必须判空（data != null），避免用户按返回键导致 data 为 null

六、新手常见错误排查指南

错误现象 核心原因 解决办法
跳转崩溃，报错 ActivityNotFoundException 目标 Activity 未注册，或类名拼写错误 确保目标 Activity 在 Manifest 中注册，类名正确
隐式 Intent 跳转无效，报错 No Activity found to handle Intent Action 不匹配，或 exported="false" 检查 Action 名称是否一致，隐式跳转的 Activity 设 exported="true"
接收数据为 null 传值的 key 和取值的 key 不一致，或类型不匹配 复制粘贴 key，确保存值和取值的类型一致
