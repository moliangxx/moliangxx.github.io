Android Intent 数据传输

🔍 核心原理

Intent 内部维护了一个 Bundle 容器，数据以 Key-Value（键值对） 形式存储：

  • 存值：通过 intent.putExtra(key, value) 将数据存入 Bundle；

  • 取值：通过 intent.getXXXExtra(key) 从 Bundle 中取出数据；

  • 核心规则：存值的 key 和取值的 key 必须完全一致（大小写、拼写均不能错）。

🛡️ 三、避坑指南（新手必看）

  1. Key 必须完全一致：存值用 key="username"，取值必须用 getStringExtra("username")，大小写、拼写不能错。

  2. 引用类型必须判空：字符串、数组、集合、自定义对象等引用类型，取值后必须用 if (xxx != null) 判空，避免空指针异常。

  3. 自定义对象必须序列化：传递自定义对象时，必须实现 Serializable 或 Parcelable 接口，否则会抛出 NotSerializableException。

  4. 避免传递过大数据：Intent 传递的数据大小有限制（约 1MB），不要传递 Bitmap、大文件等，建议用全局变量或本地存储替代。

  5. 默认值设置：基本类型取值时必须设置默认值（如 getIntExtra("key_age", 0)），避免 key 不存在时返回 null 导致崩溃。

✅ 核心要点总结

  1. 存值用 putExtra，取值用 getXXXExtra，key 必须完全一致；

  2. 基本类型直接传，自定义对象需实现 Serializable；

  3. 引用类型必须判空，基本类型设置默认值；

  4. 多数据用 Bundle 批量传，双向传递用 startActivityForResult。
