实现方式:

方式一:【OptionMenu】

核心特点

  1. 触发方式：点击页面顶部 ActionBar 最右侧的「三个竖点 / 三个点」图标 触发，点击后下拉展示菜单列表；

  2. 核心依赖：强依赖 ActionBar（顶部标题栏） → 【重中之重】有 ActionBar 则菜单能显示，无 ActionBar 则菜单彻底消失，没有任何例外！

  3. 显示位置：固定在ActionBar 右侧下拉弹出，菜单位置由系统决定，无法手动修改 / 自定义位置；

  4. 生命周期：页面创建时自动加载，页面销毁时自动销毁，全局唯一，一个 Activity 只能有一个 OptionMenu；

  5. 绑定关系：和整个 Activity 绑定，不是绑定某个控件，属于页面的「全局菜单」；

  6. 视觉样式：跟随系统主题样式，菜单是下拉列表，无动画，简洁原生；

  7. 适用版本：兼容所有 Android 版本，是 Android 从诞生就有的菜单形式，官方原生支持。

方式二:【PopupMenu 弹出式菜单】

✨ 🔶 核心特点（精准总结，必记）

  1. 触发方式：点击控件触发（点击按钮 / 文本 / 图片等任意控件），是「点击式交互」，符合用户最直观的操作习惯；

  2. 显示位置：默认在触发控件的正下方弹出，也可手动指定在控件上方 / 左侧 / 右侧弹出，位置精准、固定，不会乱跑；

  3. 绑定关系：一个 PopupMenu 绑定一个触发控件，点击哪个控件，菜单就在哪个控件旁弹出；

  4. 生命周期：点击菜单 / 点击空白处，菜单会自动消失，无需手动销毁，用完即走；

  5. 核心特性：轻量级、创建简单、灵活性拉满、零配置依赖、兼容性极好（所有 Android 版本可用）；

  6. 视觉特点：弹出时有平滑的小动画，菜单是「悬浮式列表」，不会遮挡页面核心内容。

方式三：【ContextMenu 上下文菜单】

✨ 🔶 核心特点（精准总结，必记）

  1. 触发方式：长按控件触发（长按按钮 / 文本 / 图片等任意控件），是 Android 系统原生的长按交互规则，所有安卓用户都有这个操作习惯；

  2. 显示位置：菜单默认在屏幕正中间弹出，系统自动适配屏幕位置，无法手动指定固定位置（系统自适应）；

  3. 绑定关系：通过代码「注册控件」绑定，给哪个控件注册，长按哪个控件就会弹出菜单，支持给多个控件注册同一个菜单；

  4. 生命周期：点击菜单选项自动消失，点击空白处也会消失，无需手动销毁；

  5. 核心特性：原生系统风格、无需单独写点击方法、适配性极强，是安卓系统的「标配菜单」；

  6. 视觉特点：菜单是「系统原生样式列表」，无多余动画，简洁、统一，和系统行为一致。
