总结

  1. 核心语法差异：Java 版需用 findViewById 手动绑定控件、匿名内部类实现监听，而 Kotlin 有语法糖；但 Fragment 核心 API（FragmentManager、FragmentTransaction）完全一致。

  2. 动态替换关键步骤：获取管理器 → 开启事务 → 替换 Fragment → （可选）加入返回栈 → 提交事务，这是《第一行代码》中动态使用 Fragment 的核心流程。

  3. 通信原则：Java 版通过接口回调实现 Fragment 和 Activity 通信，需注意 onAttach 绑定接口、onDetach 清空接口，避免内存泄漏。
