核心技巧：

  • ViewPager2 优势：支持垂直滑动、更优的内存管理（FragmentStateAdapter 会销毁不可见 Fragment），替代旧版 ViewPager。

  • 禁止滑动：viewPager2.setUserInputEnabled(false)，强制用户通过底部按钮切换，符合底部导航交互逻辑。

  • 状态同步：通过 registerOnPageChangeCallback 监听滑动，同步更新底部按钮选中状态。

2. Fragment 懒加载（按需加载数据）

场景：底部导航有 3 个 Fragment，默认初始化时会加载所有 Fragment 的数据（如网络请求），导致启动变慢。懒加载 指：只有 Fragment 可见时才加载数据。

实现方式（基于 ViewPager2 + Fragment）：
（1）创建懒加载基类 Fragment（LazyLoadFragment.java）
（2）子类 Fragment 继承基类，实现懒加载
核心原理：

  • setUserVisibleHint(boolean isVisibleToUser)：ViewPager2 中 Fragment 可见 / 不可见时会触发该方法，用于判断可见状态。

  • 懒加载三条件：布局已创建（isViewCreated） + Fragment 可见（isVisible） + 未加载数据（!isDataLoaded），满足则执行 loadData()。

  • 避免重复加载：用 isDataLoaded 标记，加载一次后不再重复请求。

2. 避免 Fragment 内存泄漏的技巧

  • 避免在 Fragment 中使用非静态内部类：

    非静态内部类会持有外部 Fragment 的引用，若内部类做耗时操作（如线程），会导致 Fragment 无法回收。解决方案：用静态内部类 + 弱引用。
