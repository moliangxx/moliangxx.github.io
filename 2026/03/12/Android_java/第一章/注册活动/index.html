活动（Activity）的注册

注册活动的步骤

  • 步骤 1：在 AndroidManifest.xml 的 <application> 标签内部，添加 <activity> 标签。

    比如要注册 MainActivity，可以这样写：

  • 步骤 2：关键属性解释

    • android:name=".MainActivity"：指定要注册的活动类名，. 代表当前包名（com.example.my_firstproject）。

    • android:exported="true"：表示该活动是否可以被其他应用启动，主活动必须设为 true。

    • <intent-filter>：这个过滤器是用来声明活动的角色，包含 MAIN 和 LAUNCHER 的就是应用的入口活动，桌面图标点击后会启动它。

    • android:exported 核心作用

      • false ：只允许Android activity内部访问
      • true：允许系统和android activity访问
      • 隐式intent是系统访问
      • 显示intent是activity访问

  • 确保活动类名和包名对应正确，否则会出现找不到类的错误。
