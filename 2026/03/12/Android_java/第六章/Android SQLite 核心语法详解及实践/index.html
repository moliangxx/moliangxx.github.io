Android SQLite 核心语法详解及实践

先对齐教材里的核心表结构

我们以教材中的 Book 表为例，先明确表结构（这是写 SQL 的基础）：

列名 类型 说明
id INTEGER 主键、自增（主键唯一标识每条数据）
name TEXT 书名（字符串类型）
author TEXT 作者（字符串类型）
pages INTEGER 页数（整数类型）
price REAL 价格（浮点类型）

关键说明（教材重点）：

  • PRIMARY KEY：主键约束，保证该列的值唯一（比如每本书的 id 都不一样）；

  • AUTOINCREMENT：自增约束，只对 INTEGER 主键生效，插入数据时不用手动给 id 赋值，数据库会自动分配；

  • SQLite 常用数据类型：TEXT（字符串）、INTEGER（整数）、REAL（浮点数）、BLOB（二进制，比如图片）。

关键说明（教材重点）：

  • * 是通配符，代表查询所有列，教材里 db.query("Book", null, ...) 就是对应 SELECT * FROM Book；

  • Cursor 就是查询结果的 “容器”，cursor.moveToFirst() 是移动到第一行结果，cursor.moveToNext() 是遍历下一行，对应 SQL 查询结果的每一行；

  • 取值时 cursor.getString(cursor.getColumnIndex("name"))，本质是从查询结果的 name 列取值。

总结

  1. 教材里的 SQLite 核心 SQL 语法就 5 类：CREATE（建表）、INSERT（增）、UPDATE（改）、DELETE（删）、SELECT（查）；

  2. 重点记住：WHERE 子句控制增删改查的范围，不加会操作所有行；字符串值用单引号包裹，主键自增不用手动赋值；

  3. Android 里的 ContentValues、Cursor 都是对这些 SQL 语法的封装，理解了底层 SQL，就能看懂教材里的代码逻辑。
