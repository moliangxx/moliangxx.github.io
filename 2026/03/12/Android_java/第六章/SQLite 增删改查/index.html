三、进阶注意事项

  1. 子线程执行：数据库操作耗时，主线程执行可能导致 ANR（应用无响应），建议使用AsyncTask、Thread或Coroutine（Kotlin）。

  1. SQL 注入防护：使用insert()/query()/update()/delete()的参数化方式，避免直接拼接 SQL 字符串。

  2. 版本升级：实际项目中onUpgrade不能简单删表，需编写数据迁移逻辑（如先备份数据，再升级表结构，最后恢复数据）。

  3. 权限：无需申请额外权限（SQLite 数据存储在应用私有目录，其他应用无法访问）。

总结

  1. 核心类：SQLiteOpenHelper管理数据库创建 / 升级，SQLiteDatabase执行增删改查，Cursor处理查询结果。

  2. 增删改查：优先使用参数化方法（insert()/update()/delete()/query()），避免直接执行 SQL，更安全且易维护。

  3. 资源释放：操作完成后必须关闭Cursor和SQLiteDatabase，避免内存泄漏。
