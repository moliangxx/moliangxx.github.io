SQLite 关键字

一、SQL 关键字分类（按操作场景）

1. 数据库 / 表管理关键字（创建 / 删除 / 升级）

关键字 作用 示例（结合你的 Book 表）
CREATE 创建数据库 / 表 / 索引 CREATE TABLE Book (id INTEGER PRIMARY KEY);
DROP 删除数据库 / 表 DROP TABLE IF EXISTS Book;（升级时删表）
ALTER 修改表结构（进阶，保留数据升级） ALTER TABLE Book ADD COLUMN category TEXT;（给 Book 表加分类列）
PRIMARY KEY 定义主键（唯一标识行） id INTEGER PRIMARY KEY AUTOINCREMENT
AUTOINCREMENT 主键自增（仅 INTEGER 主键） 同上，配合 PRIMARY KEY 使用
NOT NULL 约束列值非空 name TEXT NOT NULL（书名列不能为空）
UNIQUE 约束列值唯一 isbn TEXT UNIQUE（ISBN 号不能重复）

2. 数据操作关键字（增删改查核心）

关键字 作用 示例（结合你的 Book 表）
INSERT 插入数据 INSERT INTO Book (name, author) VALUES ('Android 第一行代码', '郭霖');
INTO 配合 INSERT 指定目标表 同上，固定搭配 INSERT INTO
VALUES 配合 INSERT 指定插入值 同上，固定搭配 VALUES (值1, 值2)
UPDATE 修改数据 UPDATE Book SET price=10.99 WHERE name='The Da Vinci Code';
SET 配合 UPDATE 指定修改列 同上，固定搭配 SET 列名=新值
DELETE 删除数据 DELETE FROM Book WHERE pages>500;
FROM 配合 DELETE/SELECT 指定表 同上，固定搭配 DELETE FROM/SELECT FROM
SELECT 查询数据 SELECT * FROM Book WHERE price<20;
* 通配符（查询所有列） 同上，SELECT * 表示查 Book 表所有列
WHERE 筛选条件（增删改查都可用） 所有带条件的操作都需要，如 WHERE name=?
ORDER BY 排序查询结果 SELECT * FROM Book ORDER BY price DESC;（按价格降序）
ASC 升序排序（默认） ORDER BY price ASC
DESC 降序排序 同上 DESC 示例
LIMIT 限制查询结果数量 SELECT * FROM Book LIMIT 5;（只查前 5 条）
AND/OR 多条件筛选 SELECT * FROM Book WHERE price<20 AND pages>400;

3. 聚合函数关键字（统计 / 计算，进阶）

关键字 作用 示例（结合你的 Book 表）
COUNT() 统计行数 SELECT COUNT(*) FROM Book;（统计总书籍数）
SUM() 求和 SELECT SUM(price) FROM Book;（总价格）
AVG() 求平均值 SELECT AVG(price) FROM Book;（平均价格）
MAX()/MIN() 求最大 / 最小值 SELECT MAX(price) FROM Book;（最高价格）
GROUP BY 分组统计 SELECT category, COUNT(*) FROM Book GROUP BY category;（按分类统计数量）

二、关键字使用核心规则（避坑）

  1. 大小写不敏感，但推荐大写：SQLite 中 select 和 SELECT 效果一样，但大写关键字能让代码更易读（教材 / 企业规范都推荐大写）；

  2. 关键字不能作为表名 / 列名：比如不能把表名设为 SELECT、列名设为 WHERE，会导致 SQL 语法错误；

  3. 固定搭配要记牢：

  • 插入：INSERT INTO 表名 (列) VALUES (值)

  • 修改：UPDATE 表名 SET 列=值 WHERE 条件

  • 删除：DELETE FROM 表名 WHERE 条件

  • 查询：SELECT 列 FROM 表名 WHERE 条件 ORDER BY 列

三、和 Android API 的对应关系（重点）

你在代码中调用的 Android 方法，本质是封装了这些关键字：

Android API 方法 封装的核心关键字 示例代码
db.insert() INSERT INTO + VALUES db.insert("Book", null, values)
db.update() UPDATE + SET + WHERE db.update("Book", values, "name=?", ...)
db.delete() DELETE FROM + WHERE db.delete("Book", "pages>?", ...)
db.query() SELECT + FROM + WHERE（可选） db.query("Book", null, null, ...)
db.execSQL() 任意关键字（直接执行 SQL） db.execSQL("CREATE TABLE Book (...)")

总结

  1. SQLite 核心关键字按功能分「表管理」「数据操作」「聚合统计」三类，优先记住增删改查的固定搭配；

  2. 关键字推荐大写，避免和表名 / 列名重名；

  3. Android API 是对 SQL 关键字的封装，理解关键字含义能更快看懂 API 作用。
