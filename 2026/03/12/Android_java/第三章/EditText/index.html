EditText

核心需求响应

EditText 是 TextView 子类，核心用于「用户输入」，新增「输入控制、交互反馈」特有属性。以下按「核心属性（分场景）+ 基础使用 + 关键技巧」梳理，精炼覆盖开发高频场景，无冗余内容，与之前 TextView/Button 结构保持一致。

一、核心属性（分场景，仅列高频）

分类 属性名 作用（精炼版） 示例值
基础文本（继承 TextView） android:text 初始输入文本 默认内容/@string/default
android:hint 输入提示（无内容时显示） 请输入用户名
android:textSize 字体大小（单位 sp） 16sp
android:textColor 输入文本颜色 #333333/@color/text_black
android:textColorHint 提示文本颜色 #999999
输入控制 android:inputType 输入类型（限制输入格式） text/number/textPassword
android:maxLength 最大输入长度 11（手机号）/20（用户名）
android:maxLines 最大输入行数（多行输入用） 1（单行）/3（多行）
android:imeOptions 软键盘右下角按钮样式 actionDone（完成）/actionNext（下一步）
外观样式 android:background 背景（颜色 / 选择器 / 圆角） @drawable/edit_bg/#F5F5F5
android:padding 内边距（输入文本与边框间距） 10dp
android:hintTextColor 提示文本颜色（同 textColorHint） #999999
交互反馈 android:enabled 是否启用输入（禁用时灰显） false（禁止输入）
android:clickable 是否可点击（默认 true） false（不可点击）
android:focusable 是否获取焦点（默认 true） true（允许输入）
辅助功能 android:drawableRight 右侧图标（如清除按钮） @drawable/ic_clear
android:drawablePadding 图标与文本间距 5dp
android:hint 输入提示（无内容时显示） 请输入密码

四、核心总结（关键点回顾）

  1. 属性核心：继承 TextView 文本属性，重点关注「输入控制（inputType/maxLength）、提示样式（hint/textColorHint）、交互反馈（enabled/focusable）」；

  2. 使用原则：XML 定静态样式（输入类型、圆角、提示），代码改动态状态（获取输入、清空、启用 / 禁用）；

  3. 必备技巧：输入类型精准控制（避免非法输入）、圆角边框（优化 UI）、文本变化监听（实时校验）、软键盘控制（提升体验）。
