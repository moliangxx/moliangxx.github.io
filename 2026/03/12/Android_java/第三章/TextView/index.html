一、核心属性（按场景分类，只列高频）

分类 属性名 作用（精炼版） 示例值
文本内容 android:text 设置显示文本 Hello TextView/@string/hello
android:hint 占位提示文本（无内容时显示） 请输入内容
android:textColor 文本颜色 #FF0000/@color/red
android:textColorHint 提示文本颜色 #999999
文本样式 android:textSize 字体大小（单位 sp，适配屏幕） 16sp
android:textStyle 字体样式 bold/italic/`bold
android:maxLines 最大显示行数 2（超过则截断）
android:ellipsize 文本溢出时省略号位置 end（末尾）/middle（中间）
android:singleLine 是否单行显示（已过时，用 maxLines=1） true
对齐与排版 android:gravity 文本在控件内的对齐方式 center/`left
android:textAlignment 文本对齐（替代 gravity） center
布局与尺寸 android:layout_width 控件宽度 match_parent/wrap_content/100dp
android:layout_height 控件高度 同上
android:padding 控件内边距（文本与边框间距） 10dp
交互 android:clickable 是否可点击 true
android:autoLink 自动识别链接（电话 / 网址 / 邮箱） web/phone/all
外观 android:background 背景（颜色 / 图片 / 形状） #F5F5F5/@drawable/bg_text
滚动 android:scrollHorizontally 单行文本溢出时横向滚动 true
