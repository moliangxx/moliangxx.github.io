主题：AlertDialog 的核心配置、基础使用及关键技巧，包括封装通用确认对话框、自定义对话框样式、加载对话框和避免内存泄漏等内容

核心需求响应

AlertDialog 核心用于「弹出交互对话框」（提示、确认、输入、选择），核心逻辑围绕「 Builder 构建 + 按钮 / 内容配置」。以下按「核心属性 / 配置（分场景）+ 基础使用（高频场景）+ 关键技巧」梳理，与之前控件结构保持一致，精炼覆盖开发 95% 高频场景，无冗余内容。

一、核心配置（分场景，仅列高频）

AlertDialog 主要通过 AlertDialog.Builder 动态配置（XML 仅需简单布局容器），核心配置按场景分类：

分类 配置方式（Builder 方法） 作用（精炼版） 示例值 / 代码
基础信息 setTitle(String title) 设置对话框标题 setTitle("提示")
setMessage(String msg) 设置对话框内容 setMessage("确定要删除吗？")
setIcon(int resId) 设置对话框图标 setIcon(R.drawable.ic_warning)
按钮配置 setPositiveButton(文本, 点击监听) 确定按钮（右侧） setPositiveButton("确定", (d, i)->{})
setNegativeButton(文本, 点击监听) 取消按钮（左侧） setNegativeButton("取消", (d, i)->d.dismiss())
setNeutralButton(文本, 点击监听) 中性按钮（中间，可选） setNeutralButton("稍后", (d, i)->d.dismiss())
内容类型 setView(View view) 自定义内容（输入框 / 列表等） setView(R.layout.dialog_input)
setItems(数组, 点击监听) 列表型对话框（单选） setItems(new String[]{"A","B"}, (d, i)->{})
交互控制 setCancelable(boolean flag) 是否可通过返回键取消 setCancelable(false)（不可取消）
setCanceledOnTouchOutside(boolean flag) 点击外部是否取消 setCanceledOnTouchOutside(false)
