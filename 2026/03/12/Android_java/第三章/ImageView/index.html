ImageView

核心需求响应

ImageView 核心用于「显示图片」，核心属性围绕「图片加载、缩放、样式」设计。以下按「核心属性（分场景）+ 基础使用 + 关键技巧」梳理，与之前控件结构保持一致，精炼覆盖开发高频场景，无冗余内容。

一、核心属性（分场景，仅列高频）

分类 属性名 作用（精炼版） 示例值
图片加载 android:src 加载图片（本地 / 资源） @drawable/ic_logo/@mipmap/img_banner
android:background 背景图片 / 颜色（与 src 区分） #F5F5F5/@drawable/bg_shape
缩放模式 android:scaleType 图片缩放 / 裁剪规则（核心） centerCrop/fitCenter/fitXY
尺寸控制 android:layout_width 控件宽度 match_parent/wrap_content/100dp
android:layout_height 控件高度 同上
android:adjustViewBounds 保持图片宽高比（配合 wrap_content） true
android:maxWidth 最大宽度（避免图片过大） 200dp
android:maxHeight 最大高度 200dp
外观样式 android:tint 图片着色（改变图片颜色） #FF0000/@color/red
android:alpha 透明度（0-1，0 = 完全透明） 0.5
交互行为 android:clickable+android:focusable 是否可点击（默认 false） true（需加点击监听时设）
android:foreground 前景覆盖（如点击态遮罩） @drawable/selector_img_click

三、关键技巧（解决核心需求）

1. 缩放模式选择（开发高频，必懂）

缩放模式 效果（精炼版） 适用场景
center 图片居中，不缩放（超出控件部分裁剪） 图片尺寸与控件一致时
fitCenter 保持宽高比，缩放至控件能容纳（不裁剪） 展示完整图片（如 logo）
centerCrop 保持宽高比，缩放至填满控件（裁剪多余部分） 展示 banner、封面图
fitXY 拉伸图片填满控件（不保持宽高比，易变形） 背景图、无需保持比例的图
fitStart 保持宽高比，靠左上角显示 列表图标统一对齐

2. src vs background 核心区别（新手必避坑）

维度 android:src android:background
作用 显示前景图片（核心图片） 显示背景（颜色 / 图片 / 形状）
缩放影响 受 scaleType 控制 不受 scaleType 控制，拉伸填满控件
层级关系 前景（在上方） 背景（在下方）
适用场景 展示图标、图片内容 控件背景、圆角边框、点击态

四、核心总结（关键点回顾）

  1. 属性核心：重点关注「src（前景图）、scaleType（缩放）、adjustViewBounds（保持比例）」，区分 src 和 background；

  2. 使用原则：XML 定静态样式（图片、缩放模式、圆角），代码改动态状态（换图、着色、透明度）；

  3. 必备技巧：根据场景选缩放模式（centerCrop 适合封面，fitCenter 适合完整展示）、用 shape 实现圆角、foreground 加点击态。
