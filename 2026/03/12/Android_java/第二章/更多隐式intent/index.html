更多实用隐式 Intent

一、核心原则（新手必记）

所有系统隐式 Intent 都遵循：指定系统 Action + 传递对应 Data（如号码、路径、坐标），且 Android7.0 中这些场景无需手动申请权限（系统会自动弹窗询问用户授权，新手不用处理权限逻辑）。

二、8 个实用系统隐式 Intent 场景（含代码 + 说明）

场景 1：拨打电话（直接跳转到拨号界面，带默认号码）

✅ 注意：ACTION_DIAL 只是打开拨号界面（用户需手动点击拨打），如果想直接拨打电话，需用 ACTION_CALL（但需要申请权限，新手暂不推荐）。

场景 2：发送短信（跳转到短信界面，带默认号码和内容）

✅ 注意：sms_body 是系统固定的 Extra Key，用于传递短信内容，不能写错。

场景 3：打开相册（选择图片）

✅ 效果：打开手机默认相册，选择图片后可返回（如需处理选中的图片，后续会讲 onActivityResult 接收）。

场景 4：打开相机（拍照，无需权限）

✅ 注意：Android7.0 中直接拍照无需权限，拍好的照片会默认保存到系统相册（如需自定义保存路径，后续进阶学习）。

场景 5：打开地图导航（根据坐标导航到指定位置）

✅ 效果：打开手机默认地图应用（如高德、百度地图），自动定位到指定坐标并显示名称。

场景 6：打开应用市场（跳转到自己 APP 的详情页，测试用）

✅ 测试：如果是模拟器，需安装应用市场（如 Google Play）；真机直接跳转应用宝、华为应用市场等。

场景 7：发送邮件（跳转到邮件应用，带收件人、主题、内容）

✅ 注意：EXTRA_EMAIL 必须是字符串数组（支持多个收件人），setType("message/rfc822") 是邮件的固定类型。

场景 8：打开视频播放器（播放指定路径的视频，本地文件）

✅ 注意：Android7.0 中访问 SD 卡文件无需权限，只需确保文件路径正确（可在模拟器中手动放入视频文件测试）。

三、关键知识点汇总（新手必背）

1. 系统 Action 对照表（常用）

功能 系统 Action Data 格式
打开浏览器 Intent.ACTION_VIEW http://网址 或 https://网址
拨打电话 Intent.ACTION_DIAL tel:号码
发送短信 Intent.ACTION_SENDTO smsto:号码
选择图片 Intent.ACTION_PICK image/*（Type 指定）
拍照 MediaStore.ACTION_IMAGE_CAPTURE 无（系统自动处理）
地图导航 Intent.ACTION_VIEW geo:纬度,经度?name=位置名
发送邮件 Intent.ACTION_SEND 无（Type 指定为 message/rfc822）
播放视频 Intent.ACTION_VIEW file://文件路径（Type 指定为 video/*）

2. 新手避坑指南

  • Data 格式必须正确：比如拨打电话的 tel:、发送短信的 smsto:，缺少前缀会导致匹配失败；

  • 必加崩溃防护：所有隐式 Intent 都要通过 resolveActivity 判断是否有应用能处理，避免崩溃；

  • Type 类型准确：打开图片用 image/*、视频用 video/*、邮件用 message/rfc822，Type 错误会无法匹配；

  • 文件路径判断：访问本地文件（如视频、图片）时，先判断文件是否存在，再启动 Intent。

四、实战建议（贴合你的学习节奏）

  1. 逐个测试场景：先在布局中添加按钮，绑定一个场景（如拨打电话），运行测试成功后再添加下一个，避免一次性添加太多代码出错；

  2. 修改参数练习：比如把拨打电话的号码改成自己的手机号，把地图导航的坐标改成自己所在城市，加深理解；

  3. 结合教材巩固：这些场景都是《第一行代码》第二版中隐式 Intent 的拓展，学完后回头看教材，会更易理解；

  4. 记录错误：如果遇到匹配失败、文件不存在等问题，记录下来，结合 Logcat 排查，比如视频文件不存在时，Toast 会提示，方便定位问题。

五、后续进阶方向

这些场景都是 “启动系统应用并传递简单数据”，后续可以学习：

  1. 接收系统应用返回的数据（如选择图片后，用 onActivityResult 获取选中的图片路径）；

  2. 自定义隐式 Intent 的 Category（除了默认的 DEFAULT，还可以添加自定义类别）；

  3. 处理 Android7.0 中的文件 Uri 限制（如调用相机拍照后保存到自定义路径）。
