Android Button 按钮

一、Button 是什么？核心特点

  1. Button 是 Android 最常用的可点击交互控件，用于实现「点击触发事件」（比如点击弹出 Toast、跳转页面、执行功能）；

  2. Button 继承 TextView，拥有 TextView 的所有属性（文本、颜色、大小、加粗等），只是多了「可点击」的交互能力；

  3. 默认自带 Android 系统样式：灰色背景、圆角矩形、点击会有按压效果，文本居中显示。

三、Button 核心属性大全

📌 第一类：文本样式属性

属性名 作用 取值示例 注意事项
android:text 设置按钮显示的文字 "点击按钮" / @string/btn_text ✅ 推荐用 strings.xml 管理文本，禁止硬编码
android:textSize 按钮文字大小 14sp / 16sp / 18sp 必须用 sp 单位，跟随系统字体大小变化
android:textColor 按钮文字颜色 #FFFFFF / @color/white / #FF0000 十六进制格式：#RRGGBB(纯色) / #AARRGGBB(透明色)
android:textStyle 文字样式 normal/bold(加粗)/italic(斜体) 按钮文字建议加粗，更醒目
android:textAllCaps 是否强制文字大写 true/false(默认) 适合英文按钮，比如 "SUBMIT"，不用手动写大写

📌 第二类：Button 专属外观属性

属性名 作用 取值示例 新手必避坑
android:background 设置按钮背景（颜色 / 图片 / 圆角） #FF0099CC / @drawable/btn_bg ❗ 高版本 Android（API31+）直接写颜色可能无效，下文有解决方案
android:clickable 设置按钮是否可点击 true(默认可点) / false(不可点) 设置 false 后，按钮变灰色，点击无任何反应
android:enabled 设置按钮是否启用 true(默认启用) / false(禁用) 禁用状态：按钮灰色 + 文字浅灰色 + 无法点击，比 clickable 更常用
android:padding 按钮内部间距（文字与按钮边框的距离） 8dp / 10dp 增大 padding 可以让按钮更大，点击区域更广，体验更好

📌 第三类：布局约束属性

所有布局属性和 TextView 完全一致，核心就 3 个，保证按钮位置正确：

  1. app:layout_constraintTop_toBottomOf="@+id/tv_first_text" → 按钮在 TextView 下方

  2. app:layout_constraintStart_toStartOf="parent" → 按钮和父布局左对齐

  3. app:layout_constraintEnd_toEndOf="parent" → 按钮和父布局右对齐

  4. android:layout_marginTop="30dp" → 按钮和上方控件的间距

四、Button 核心中的核心：点击事件（3 种实现方式，全部适配你的项目）

Button 的唯一作用就是「被点击后执行逻辑」，所以「点击事件」是 Button 最重要的知识点，没有之一！

给你讲 开发中最常用的 3 种点击事件写法，按优先级排序：新手首选写法 1 → 开发标准写法 2 → 多按钮写法 3，全部是 Java 代码，都能直接复制到你的 MainActivity 中运行，都结合了你的 Toast 弹窗，完美适配！

方式一：XML 绑定点击事件

优点：代码最少、最简单、不用找控件、不用写复杂逻辑，适合单个按钮、简单交互；

缺点：适合简单场景，多按钮时代码分散；

方式二：Java 代码绑定点击事件

优点：逻辑和布局分离、灵活性极高、适合复杂逻辑、多按钮场景，是 Android 开发的标准规范写法；

缺点：比方式一多几行代码，但学会后受益终身；

核心逻辑：

  1. 通过按钮的 ID → 找到布局中的 Button 控件；

  2. 给按钮设置 setOnClickListener 点击监听器；

  3. 重写 onClick 方法，编写点击后的逻辑；

✔️ 完整 Java 代码（直接复制覆盖你的 MainActivity，无报错）
