AndServer 与 OkHttp 联调

AndServer 是 专为 Android 平台设计的嵌入式 Web 服务器开源库，由国内开发者严振杰维护，核心价值是让 Android App 能直接作为 HTTP 服务器运行，无需依赖外部服务，非常适合 Android 网络学习与开发。

一、核心特性（为什么适合学习）

  1. 零依赖部署：纯 Java/Kotlin 库，无需 Root 权限，直接集成到 App 内启动服务；

  2. SpringMVC 风格注解：使用 @GetMapping、@PostMapping 等注解写接口，学习曲线平缓；

  3. 功能全面：支持托管静态资源（HTML/CSS/JS）、RESTful API、HTTPS、拦截器、文件上传下载；

  4. 完美适配 Android 网络调试：App 既是客户端（用 OkHttp/Retrofit 发请求）也是服务端（AndServer 提供接口），无需电脑即可学习网络编程。

四、学习场景推荐

  1. HTTP 协议入门：通过 AndServer 托管静态页面，观察请求 / 响应流程；

  2. 接口开发与联调：编写 JSON 接口，配合 OkHttp/Retrofit 实现 Android 客户端请求；

  3. 局域网通信：两台 Android 设备（或手机与电脑）通过 AndServer 实现数据传输；

  4. 文件上传下载：利用 AndServer 的文件处理 API，学习 HTTP 文件操作。
