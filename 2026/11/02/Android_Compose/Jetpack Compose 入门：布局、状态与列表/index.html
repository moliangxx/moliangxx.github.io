Jetpack Compose 入门：布局、状态与列表

Compose 最大的变化不是“少写 XML”，而是界面是状态的函数：状态变，界面重组；界面不再自己保存数据。

一、声明式思维

没有 findViewById，没有 setText。你描述“长什么样”，Compose 负责“什么时候变”。

二、常用布局

2.1 Column / Row / Box

2.2 尺寸与约束

Modifier 作用
fillMaxWidth() 占满父容器宽度
weight(1f) 在 Row/Column 中按比例分配
wrapContentSize() 按内容大小
aspectRatio(16f / 9f) 固定比例
padding() 内边距

三、状态：remember 与状态提升

  • remember：在重组之间保留值。
  • mutableStateOf：值变化会触发读取它的组件重组。
  • rememberSaveable：进程重建后仍保留。

状态提升：可复用的组件不自己持有状态，而是由调用方传入值和回调。

这样 SearchBar 可以被任意页面复用，测试也更容易。

四、SideEffect：什么时候做“副作用”

API 用途
LaunchedEffect(key) 跟随 key 启动协程
DisposableEffect(key) 注册/注销监听
SideEffect 每次成功重组后执行
rememberCoroutineScope() 在事件回调中启动协程

五、LazyColumn：列表的正确姿势

要点：

  1. key 必须稳定，用数据库 id，不要用索引。
  2. 不要在 items 里做耗时操作。
  3. 列表项内部避免 remember 保存跨项共享状态。

六、主题与样式

字体建议用 FontFamily.Serif 做标题，正文用系统默认，保证中文回退正常。

七、和 XML 的对照

XML Compose
LinearLayout Column / Row
FrameLayout Box
ConstraintLayout ConstraintLayout composable
RecyclerView LazyColumn / LazyRow
findViewById 参数直接传入
setOnClickListener onClick lambda

八、小结

Compose 入门只需要记住三句话：

  1. 界面是状态的函数；
  2. 状态用 remember 保存，跨组件用状态提升；
  3. 列表用 LazyColumn，key 要稳定。
