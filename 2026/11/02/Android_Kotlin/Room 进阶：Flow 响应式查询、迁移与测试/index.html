六、测试 DAO

七、性能与工程建议

  1. 不要在事务里做网络请求，Room 事务会占用数据库连接。
  2. 大列表分页用 Paging 3 + PagingSource，不要一次 SELECT *。
  3. 字段命名统一：@ColumnInfo(name = "updated_at") 保持与 SQL 一致。
  4. 导出 schema：room.schemaLocation 指向 schemas/，迁移测试才有依据。
  5. 加密需求：SQLCipher + Room，注意密钥不要硬编码。

八、小结

Room 的进阶重点不是 API，而是三件事：

  • 用 Flow 让 UI 自动跟随数据；
  • 用正式迁移保住用户数据；
  • 用内存数据库把 DAO 测起来。

把这三件事做好，本地数据层就基本不会出问题了。
