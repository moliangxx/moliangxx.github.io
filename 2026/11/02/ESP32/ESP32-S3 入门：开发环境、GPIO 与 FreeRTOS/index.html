ESP32-S3 入门：开发环境、GPIO 与 FreeRTOS

ESP32-S3 是乐鑫面向“带屏幕 + 带摄像头 + 轻量 AI”场景的芯片：双核 LX7、Wi-Fi + BLE 5、USB OTG、足够的 PSRAM，价格还不高。这篇记录从点灯到多任务的第一条路径。

一、芯片要点

项目 ESP32-S3
内核 双核 Xtensa LX7，最高 240 MHz
内存 512 KB SRAM + 外部 PSRAM（模组常见 2/8 MB）
无线 2.4 GHz Wi-Fi 4 + BLE 5
GPIO 最多 45 个可用引脚（具体看模组）
总线 USB OTG、SPI、I2C、I2S、UART、TWAI(CAN)
特色 向量指令，适合轻量神经网络推理

常见模组：ESP32-S3-WROOM-1（无屏方案）、ESP32-S3-WROOM-1-N16R8（16MB Flash + 8MB PSRAM）、ESP32-S3-DevKitC-1 开发板。

二、开发环境

2.1 Arduino IDE / arduino-cli

  1. 安装 ESP32 开发板支持（Boards Manager 搜索 esp32，选择 Espressif Systems）。
  2. 开发板选择 ESP32S3 Dev Module。
  3. 关键选项：
选项 建议
Flash Size 按模组选择（N16R8 选 16MB）
PSRAM 有 PSRAM 的模组选 OPI PSRAM
Partition Scheme 大程序选 16M Flash (3MB APP/9.9MB FATFS)
USB CDC On Boot 用 USB 直连串口时开启

如果上传失败，按住 BOOT 再点 RST 进入下载模式，再松开 BOOT。

2.2 ESP-IDF

Windows 下用 ESP-IDF Installer 或 VS Code 的 ESP-IDF 插件更省事。

3.2 需要避开的引脚

引脚 用途 注意
GPIO0 BOOT / Strapping 上电电平影响启动模式
GPIO3 / 45 / 46 Strapping 上电时不要强拉
GPIO19 / 20 USB D- / D+ 用 USB 时不要占用
GPIO26–32 Flash / PSRAM 部分模组内部占用
GPIO33–37 Octal PSRAM 使用 OPI PSRAM 时被占用

结论：外设优先选 1–18、21、38–42、47–48，具体以你手上模组的原理图为准。

3.3 ADC 与 Wi-Fi 冲突

S3 有两组 ADC：

  • ADC1：GPIO1–GPIO10
  • ADC2：GPIO11–GPIO20

Wi-Fi 工作时 ADC2 不可用，所以模拟采样优先用 ADC1。

四、FreeRTOS：把任务分到两个核

ESP32-S3 是双核，Arduino 的 loop() 默认跑在 core 1。耗时任务可以单独开任务并绑核。

经验分配：

任务 建议核心
Wi-Fi / MQTT / HTTP core 0（协议栈默认）
屏幕刷新 / 动画 core 1
传感器采样 core 0 或 1，低优先级
神经网络推理 core 1，单独高优先级

七、常见问题

  1. 上传后串口无输出：确认 USB CDC On Boot，或换 UART 口。
  2. PSRAM 识别不到：模组型号与 PSRAM 选项要匹配（OPI / QSPI）。
  3. 一接 Wi-Fi 就重启：多半是供电不足，Wi-Fi 峰值电流可达 300mA。
  4. GPIO 电平不对：先查 strapping 与模组占用，再怀疑代码。
  5. ADC 读数漂移：加 100nF 滤波，并避开 Wi-Fi 工作时段。

八、小结

入门 ESP32-S3 的路线：

  1. 确认模组型号与 Flash/PSRAM 配置；
  2. 点灯、按键、串口三件套；
  3. 查清引脚限制；
  4. 用 FreeRTOS 把耗时任务从 loop() 里拆出去。
