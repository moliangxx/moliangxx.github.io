Python 列表（List）语法 & 函数

列表是 Python 中可变、有序、可存储任意数据类型的容器，是最常用的数据结构之一。以下按「基础→操作→方法→高级」分类整理。

一、列表基本概念

  • 性质：可变（可修改元素）、有序（元素有固定索引）、异构（可包含不同类型元素，如数字、字符串、列表等）

  • 标识：用方括号 [] 包裹，元素间用逗号分隔

二、列表创建方法

方法 语法 & 示例 说明
直接创建 lst = [1, "a", True, [2,3]] 最常用，元素可混合类型
空列表 empty_lst = [] 或 empty_lst = list() 初始化空列表
list() 转换 lst = list("abc") → ['a','b','c']；lst = list((1,2,3)) → [1,2,3] 转换可迭代对象（字符串、元组等）为列表
列表推导式 lst = [i*2 for i in range(5)] → [0,2,4,6,8] 简洁生成列表（见「九、列表推导式」）
生成器表达式转列表 lst = list(i**2 for i in range(3)) → [0,1,4] 生成器转列表（节省内存）

五、列表元素添加

方法 语法 & 示例 说明
append() lst.append(5) → 列表末尾加单个元素（可是任意类型） 常用，直接修改原列表，无返回值
extend() lst.extend([6,7]) → 列表末尾加可迭代对象的所有元素（如列表、元组） 区别于append()（append 加整个对象）
insert() lst.insert(1, "a") → 在索引 1 的位置插入元素 “a” 指定位置插入，原元素后移

六、列表元素删除

方法 语法 & 示例 说明
del 语句 del lst[1]（删索引 1 的元素）；del lst[2:4]（删切片） 直接删除元素 / 切片，修改原列表
remove() lst.remove("b") → 删除第一个匹配的元素 “b” 若元素不存在，报ValueError
pop() lst.pop() → 删末尾元素并返回；lst.pop(2) → 删索引 2 的元素并返回 若索引越界，报IndexError
clear() lst.clear() → 清空列表，变为空列表[] 保留列表对象，仅清空元素

七、列表常用操作

操作 语法 & 示例 说明
拼接（+） lst1 + lst2 → 合并两个列表（返回新列表，不修改原列表） 等价于lst1.extend(lst2)（但 extend 修改原列表）
重复（ *） lst * 2 → 列表元素重复 2 次（返回新列表） 如[1,2]*2 → [1,2,1,2]
成员检查 2 in lst → 返回True/False；2 not in lst → 相反 检查元素是否在列表中
长度（len） len(lst) → 返回列表元素个数 空列表返回 0
最大值（max） max(lst) → 返回列表中最大元素（元素需可比，如数字、字符串） 若元素不可比（如混合数字和字符串），报TypeError
最小值（min） min(lst) → 返回列表中最小元素 同max的限制
求和（sum） sum(lst) → 返回列表中数字元素的和 元素需为数字类型

八、列表内置方法（核心）

方法 语法 & 示例 说明
sort() lst.sort() → 原地升序排序；lst.sort(reverse=True) → 降序；lst.sort(key=len) → 按元素长度排序 直接修改原列表，无返回值（返回None）
sorted() new_lst = sorted(lst) → 返回新的排序列表，不修改原列表 区别于sort()（sorted返回新列表）
reverse() lst.reverse() → 原地反转列表元素 直接修改原列表，无返回值
count() lst.count(2) → 返回元素 2 在列表中出现的次数 统计元素频次
index() lst.index(2) → 返回元素 2 的第一个索引；lst.index(2, 1, 5) → 在索引 1-4 中找 2 元素不存在报ValueError
copy() new_lst = lst.copy() → 浅复制列表（见「十、列表复制」） 等价于lst[:]

2. 列表复制（浅复制 vs 深复制）

列表是可变对象，直接赋值是引用传递（修改新列表会影响原列表），需用复制方法：

复制方式 语法 & 示例 说明
浅复制（切片） new_lst = lst[:] 仅复制外层列表，嵌套列表仍为引用
浅复制（copy()） new_lst = lst.copy() 同切片复制
深复制（deepcopy） import copy; new_lst = copy.deepcopy(lst) 完全复制所有层级元素（嵌套列表也独立）

十一、常见易错点

  1. append()** vs **extend()：

  • append(x)：将 x 作为单个元素加入列表（x 可以是任意类型）

  • extend(x)：将 x（可迭代对象）的所有元素加入列表

  1. sort()** vs **sorted()：

  • sort()：原地排序，无返回值（不要写lst = lst.sort()，会得到None）

  • sorted()：返回新的排序列表，不修改原列表

  1. 列表是引用类型：直接赋值new_lst = lst是引用，修改new_lst会影响lst，需用复制方法

  2. 索引越界：访问lst[len(lst)]会报IndexError，索引最大为len(lst)-1

快速复习索引

  • 创建：[] / list() / 推导式

  • 访问：索引（0/-1）、切片（[start:end:step]）

  • 添加：append()/extend()/insert()

  • 删除：del/remove()/pop()/clear()

  • 方法：sort()/reverse()/count()/index()

  • 高级：推导式、遍历（enumerate）、复制（浅 / 深）
