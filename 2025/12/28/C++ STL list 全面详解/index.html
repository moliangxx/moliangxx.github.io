C++ list全面详解

一、核心基础：头文件与 list 特性

1. 头文件（必须包含）

2. list 核心特性（双向链表）

  • 存储结构：非连续内存，每个元素是独立节点（包含数据 + 前后指针）

  • 核心优势：任意位置插入 / 删除高效（时间复杂度 O (1)，仅需修改指针）

  • 核心劣势：不支持随机访问（不能用 [] 或 at() 访问元素，需遍历）

  • 迭代器类型：双向迭代器（支持 ++/--，不支持 +=n/-=n）

  • 适用场景：插入 / 删除频繁、无需随机访问的场景（如任务队列、频繁修改的列表）

二、完整语法：构造、迭代器、成员函数

3. 与 algorithm 库算法搭配

list 支持部分 algorithm 库算法（需满足双向迭代器要求），常用搭配如下：

算法函数 用途 示例
for_each() 遍历元素（替代手动循环） for_each(lst.begin(), lst.end(), [](int val){cout << val;});
find() 查找元素（返回迭代器，未找到返回 end ()） auto it = find(lst.begin(), lst.end(), 3);
count() 统计元素出现次数 int cnt = count(lst.begin(), lst.end(), 2);
replace() 替换元素 replace(lst.begin(), lst.end(), 2, 20); // 把所有 2 换成 20
reverse() 反转（与成员函数效果一致） reverse(lst.begin(), lst.end());

⚠️ 注意：algorithm 库的 sort() 不支持 list（需随机访问迭代器），必须用 list 自带的 sort() 成员函数！

五、list 与 vector 对比（选择依据）

特性 list（双向链表） vector（动态数组）
存储方式 非连续节点 连续内存
随机访问 不支持（O (n)） 支持（O (1)）
插入 / 删除（中间） 高效（O (1)） 低效（O (n)，需移动元素）
插入 / 删除（首尾） O(1) 尾插 O (1)（扩容时 O (n)），头插 O (n)
迭代器 双向迭代器（++/–） 随机访问迭代器（支持 +=n）
内存开销 高（每个节点含前后指针） 低（仅存储数据）
适用场景 频繁插入 / 删除、无需随机访问 频繁随机访问、少量插入删除（尾部）

六、实践总结

  1. 核心用法：记住 list 的 “双向链表” 本质，优先用于插入删除频繁的场景；

  2. 迭代器注意：不能用 [] 访问，遍历用 iterator 或范围 for 循环；

  3. 算法选择：排序用 list.sort()，查找 / 统计用 algorithm 库的 find()/count()；

  4. 搭配场景：嵌套容器（vector<T>>）、作为 stack/queue 底层容器。
