Markdown 基础语法详解

你想要掌握 Markdown（简称 MD）的基础语法，它是一种轻量级标记语言，用简单的符号标记文本格式，易写易读，无需复杂排版操作，广泛用于笔记、文档、博客、GitHub 说明文档等场景。下面是核心基础语法的详细讲解，附带示例和效果说明：

一、 标题（Heading）

Markdown 支持 6 级标题，对应 HTML 的<h1>到<h6>，用#号表示，#的数量对应标题级别（#越多，标题级别越低，字号越小）。

语法规则

  1. # 后面必须加一个空格（否则不会被识别为标题）

  2. 1 级标题（#）字号最大，6 级标题（######）字号最小

语法规则

三、 列表（List）

支持有序列表和无序列表，还可以实现列表嵌套，用于整理结构化内容。

1. 无序列表（Unordered List）

语法规则

用 **-、+、*** 三者之一作为列表项标记，标记后面必须加一个空格，三者效果一致。

用于插入跳转链接，分为行内式链接（最常用）和参考式链接（适合大量重复链接），这里重点讲解行内式。

  2. 可选标题：用双引号包裹，鼠标悬浮在链接上时会显示该标题（可省略）

六、 引用（Blockquote）

用于引用他人观点、文献内容等，生成带有缩进和背景色的引用块。

语法规则

  1. 用 **>** 作为引用标记，>后面可以加空格（推荐），也可以不加

  2. 支持嵌套引用（多个>），对应多层缩进

  3. 引用块内可以嵌套其他 Markdown 语法（如标题、列表、粗体等）

七、 代码（Code）

用于展示代码片段，分为行内代码和代码块两种场景。

1. 行内代码（Inline Code）

语法规则

八、 分隔线（Horizontal Rule）

用于分隔不同内容模块，使文档结构更清晰。

语法规则

在单独一行中输入三个及以上的*、-、_，可以混合使用，行内不能有其他字符（可以有空格，不影响效果）。

渲染效果（四种写法效果一致）

九、 表格（Table）

用于展示结构化数据，Markdown 表格支持简单的对齐设置。

语法规则

  1. 第一行：表头内容，用|分隔各列（首尾|可省略）

  2. 第二行：分隔线，用|分隔各列，用-表示分隔线，可通过:设置对齐方式

  • :---：左对齐（默认，可省略:）

  • :---:：居中对齐

  • ---:：右对齐

  1. 第三行及以后：表格内容，用|分隔各列

总结

Markdown 基础语法的核心特点是简单直观、易记易用，核心要点回顾：

  1. 标题用#，层级对应#的数量，记得加空格；

  2. 文本格式靠*、_、~~，粗体双标记、斜体单标记、删除线双波浪线；

  3. 列表分有序（数字 +.）和无序（-/+/*），支持嵌套；

  4. 链接和图片语法相似，图片多一个!；

  5. 代码分单行（`）和多行（```），多行可指定语言高亮；

  6. 引用用>，分隔线用三个及以上*,-,_。
