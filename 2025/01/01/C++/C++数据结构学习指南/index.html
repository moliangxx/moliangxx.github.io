C++数据结构学习指南

一、前置基础（1-2 周）：夯实 C++ 核心能力

数据结构的实现依赖 C++ 语法特性，需先掌握以下核心内容：

  1. C++ 基础语法：变量、指针、引用、数组、结构体（struct）、枚举

  2. 面向对象编程（OOP）：类（class）、构造 / 析构函数、继承、多态、封装

  3. STL 核心容器与算法：

  • 容器：vector（动态数组）、list（双向链表）、stack（栈）、queue（队列）、map/unordered_map（映射）

  • 算法：迭代器遍历、sort排序、find查找（理解 STL 底层实现思路，为手写数据结构打基础）

  1. 常用工具：指针操作（new/delete）、模板（template）、异常处理（可选）

实践任务：

  • 用 C++ 实现简单结构体（如Person），完成增删改查

  • 熟练使用 STL 容器解决基础问题（如用vector存储数据并排序）

二、线性数据结构（2-3 周）：入门核心基础

线性结构是数据结构的基石，重点掌握「存储逻辑」和「增删改查效率」：

1. 数组与动态数组

  • 核心要点：静态数组（固定大小）、动态数组（手动管理内存，模拟vector）

  • 实现目标：手写动态数组（支持扩容、缩容、按下标访问、插入 / 删除元素）

  • 应用场景：随机访问频繁的场景（时间复杂度 O (1)）

2. 链表（重点难点）

  • 核心类型：单链表、双链表、循环链表

  • 实现目标：

    • 单链表：头插 / 尾插、指定位置插入、删除节点、反转链表、查找中间节点

    • 双链表：双向遍历、插入 / 删除（处理前后指针关系）

  • 关键技巧：虚拟头节点（简化边界判断）、指针操作（避免野指针）

  • 应用场景：插入 / 删除频繁的场景（时间复杂度 O (1)，无需移动元素）

3. 栈（LIFO）

  • 核心特性：先进后出，仅在栈顶操作

  • 实现方式：

    • 数组实现（顺序栈，简单高效）

    • 链表实现（链式栈，无扩容问题）

  • 应用场景：括号匹配、表达式求值（后缀表达式）、函数调用栈

  • 实践：用栈解决「有效的括号」「最小栈」问题

4. 队列（FIFO）

  • 核心特性：先进先出，队首出、队尾入

  • 核心类型：

    • 普通队列：数组 / 链表实现

    • 循环队列（重点）：解决普通数组队列的「假溢出」问题

    • 双端队列（deque）：两端均可操作（结合 STL 理解）

  • 应用场景：任务调度、广度优先搜索（BFS）

  • 实践：手写循环队列，用队列实现「层序遍历」

三、非线性数据结构（3-4 周）：提升复杂问题处理能力

非线性结构是面试高频，重点掌握「树」和「图」的遍历与应用：

1. 树（重点）

  • 基础概念：节点、父 / 子节点、叶子节点、深度 / 高度、二叉树、多叉树

  • 核心类型：

    • 二叉树：满二叉树、完全二叉树、二叉搜索树（BST）

    • 平衡二叉树：AVL 树、红黑树（理解特性，无需手写实现）

  • 核心算法（必须熟练）：

    • 遍历：前序（根 - 左 - 右）、中序（左 - 根 - 右）、后序（左 - 右 - 根）、层序（BFS）

      • 实现方式：递归（简单）、迭代（面试常考，用栈 / 队列模拟）

    • 应用：二叉树的构建、节点查找、深度计算、路径总和

  • 实践任务：

    • 手写二叉树的递归 / 迭代遍历

    • 实现二叉搜索树（支持插入、查找、删除，利用中序遍历有序特性）

2. 堆（优先队列）

  • 核心特性：完全二叉树实现，分为大顶堆（父 > 子）、小顶堆（父 < 子）

  • 核心操作：建堆、插入、删除堆顶（堆化调整）

  • 应用场景：TopK 问题（如最大的 k 个元素）、堆排序、优先队列

  • 实践：用堆实现「最小的 k 个数」「合并 k 个有序链表」

3. 图（难点）

  • 基础概念：顶点、边、有向图 / 无向图、权重、邻接矩阵 / 邻接表（存储方式）

  • 核心算法：

    • 遍历：深度优先搜索（DFS，递归 / 栈）、广度优先搜索（BFS，队列）

    • 最短路径：Dijkstra 算法（单源最短路径，无负权边）、Floyd 算法（多源最短路径）

    • 拓扑排序（有向无环图 DAG，应用于任务调度）

  • 实践任务：

    • 用邻接表存储图，实现 DFS 和 BFS 遍历

    • 用 Dijkstra 算法求单源最短路径

四、高级数据结构与算法（4-6 周）：面试进阶必备

掌握高频高级结构，提升效率优化能力：

1. 哈希表（Hash Table）

  • 核心原理：哈希函数（映射键值）、哈希冲突解决（链地址法、开放寻址法）

  • 实现目标：手写简单哈希表（用数组 + 链表解决冲突）

  • 应用场景：快速查找、去重、计数（如两数之和）

  • 结合 STL：unordered_map/unordered_set的底层实现与使用

2. 字符串处理

  • 核心算法：

    • 字符串匹配：暴力匹配、KMP 算法（重点理解前缀函数）

    • 常用操作：字符串反转、分割、替换、回文判断

  • 实践：用 KMP 算法解决「字符串匹配」问题，判断回文字符串

3. 排序与查找算法（结合数据结构）

  • 排序算法（手写实现 + 理解时间复杂度）：

    • 基础排序：冒泡排序、选择排序、插入排序（O (n²)）

    • 高级排序：快速排序（分治，O (nlogn)）、归并排序（分治 + 合并，稳定）、堆排序（利用堆特性）

  • 查找算法：

    • 二分查找（有序数组，O (logn)，迭代 / 递归实现）

    • 哈希查找（O (1) 平均复杂度）

  • 实践：实现快速排序和二分查找，解决「搜索旋转排序数组」问题

4. 并查集（Disjoint Set）

  • 核心用途：处理集合合并与查询（如连通分量判断）

  • 核心操作：find（查找根节点，路径压缩优化）、union（合并集合，按秩合并优化）

  • 应用场景：朋友圈、岛屿数量、最小生成树（Kruskal 算法）

  • 实践：手写并查集，解决「岛屿数量」问题

五、实战与刷题阶段（持续进行）

数据结构的核心是「应用」，通过刷题巩固知识点，推荐路线：

  1. 基础刷题：LeetCode 简单题（对应每个数据结构的基础操作）

  • 链表：206. 反转链表、21. 合并两个有序链表

  • 栈 / 队列：20. 有效的括号、102. 二叉树的层序遍历

  • 树：144. 二叉树的前序遍历、94. 二叉树的中序遍历

  1. 进阶刷题：LeetCode 中等题（综合应用）

  • 哈希表：1. 两数之和、49. 字母异位词分组

  • 堆：215. 数组中的第 K 个最大元素、347. 前 K 个高频元素

  • 图：797. 所有可能的路径（DFS/BFS）、207. 课程表（拓扑排序）

  1. 项目实战（可选，提升综合能力）：

  • 实现一个简单的通讯录（链表 / 哈希表存储）

  • 实现一个文件系统目录结构（树结构）

  • 开发一个简单的计算器（栈 + 表达式求值）

学习建议

  1. 先理解再编码：每个数据结构先想清楚「存储逻辑」和「操作原理」，再动手写代码，避免死记硬背。

  2. 重视手写实现：STL 虽然方便，但面试常考「手写数据结构」（如链表、栈、二叉树），必须手动实现 2-3 遍。

  3. 结合复杂度分析：每学一个结构，分析其增删改查的时间 / 空间复杂度，理解「为什么用这个结构」。

  4. 持续刷题：数据结构需要通过题目巩固，每天 1-2 题，坚持 1-2 个月就能显著提升。
